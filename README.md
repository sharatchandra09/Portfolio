## 🚀 Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Build production bundle**:
   ```bash
   npm run build
   ```
   Compiled assets will be output to `./dist`.
